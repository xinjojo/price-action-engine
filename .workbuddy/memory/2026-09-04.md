### 关键调研结论（有长期价值）

**1. a-stock-data 不是 Python 库。**
它是单文件 `SKILL.md`（208 KB，Markdown + 内嵌 Python），无 `setup.py`/`__init__.py`，**不能 import**。作者明确不拆目录（#21/#22/#29）。
→ 唯一接入方式：人工摘取函数进仓库自维护（Apache-2.0 需署名）。
→ 缺交易日历、缺历史涨跌停价（只有腾讯当日快照）→ **做不了日 K 主备源**。
→ 已建议降级为「交叉校验源」：复权因子（sina vs Tushare）、ST/停牌（baostock vs Tushare namechange/suspend_d）、退市日、申万行业前视偏差。用户已确认「第一阶段只设计接口」。

**2. 主板 ST 涨跌幅正在从 5% → 10%（活规则实证）。**
2012 年调为 5%；2025-06-27 沪深交易所征求意见；**2026-04-10 上交所正式发征求意见稿拟放宽至 10%**。生效日期未能确认。
→ 这是「涨跌停规则必须按日期版本化」的最有力论据，已写入文档。

**3. Tushare `stk_limit` 用 `-1` 表示当日无涨跌幅限制。**
实测证据：2020-08-24 创业板注册制首日 N康泰（+1061%）涨跌停价均为 -1.00。必须转 `None`，否则新股前 5 日全被判跌停。

**4. 主板新股涨跌幅规则存在资料冲突**（首日 44%/36% vs 前 5 日不限），推断是 2023 全面注册制前后规则不同。V0.2 需用 stk_limit 实测反推，不能拍板。

### 本轮设计中最重要的几个原创判断

- **因果写进类型**：Snapshot 带 `as_of` / `valid_for_date`（=T+1），执行引擎断言 → 未来函数从"靠自觉"变成"类型不允许"。
- **三域 + PriceBridge**：分析域 qfq / 交易域 raw / 收益域 hfq，唯一换算入口；禁止任何地方自行乘除 adj_factor（由测试扫描强制）。忘换算会差出数量级且不报错。
- **缓存只存 raw + adj_factor**，qfq 每次读取派生（前复权以"最新"为基准，每次除权历史全变）。
- **限价锁定的成交性是方向相关的**：BUY 遇一字涨停不成交，但 BUY 遇一字跌停**能**成交；SELL 反之。原需求只覆盖了一半。
- **一字板三轴分离**：几何返回 `None`（不是 0）+ 语义覆盖 `bar_bias=±100` + `tradability_score` 独立。
- **Swing 确认延迟是最大未来函数点**，用 `confirmation_lag` + 构造期断言防护。
